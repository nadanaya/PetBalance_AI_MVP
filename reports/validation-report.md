# 검증 보고서

## 통과

- Python 단위 테스트 25개 (nutrition 6개 + label_ocr 19개)
- 단위 변환 테스트: mg·g·µg·IU·천단위 콤마 100%
- Python 문법 컴파일 (app.py, src/label_ocr.py 포함)
- SQLite 스키마·시드 실행
- 외래키 및 의미 검증 6개
- Streamlit AppTest 초기 렌더링
- 초기 화면 지표: 활성 제품 4개, 확인 필요 3개, 정보 부족 2개
- Streamlit AppTest OCR 초안 흐름: 텍스트 붙여넣기 → 초안 추출 → 확인 후 추가 시 예외 없음, 활성 제품 5개로 증가, 미확인 라벨은 정보 부족으로 판정

## 미검증

- 실제 제품 라벨 OCR 정확도
- 영양 기준표의 수의영양학 검토
- 모바일 브라우저 시각 QA

## 안전 확인

- 누락 성분을 0으로 처리하지 않음
- 음수 급여량 거부
- 알 수 없는 제품 거부
- 기준값을 교육용 데모로 명시
